# 番茄钟 Mini 模式设计

## 目标

将当前“仅缩小主窗口”的半成品改为真正的主窗口紧凑模式。Mini 模式专注于计时控制，不承载导航或任务编辑；退出后完整恢复进入前的窗口和应用壳状态。

## 行为

### 进入 Mini

- 仅允许从主窗口的番茄页进入。
- 保存当前窗口尺寸、位置、是否可缩放及置顶状态。
- 隐藏 AppShell 的 TitleBar、Sidebar、全局搜索、Butler、每日回顾和截图 OCR 等非计时区域，并移除内容区常规边距与尺寸约束。
- 将窗口调整为 `340 × 160`、设为不可缩放并保持置顶。
- 显示持续同步的剩余时间、当前任务名、开始/暂停按钮和恢复按钮。
- 切换不会创建、结束或重置番茄会话。

### 退出 Mini

- 恢复进入前保存的窗口尺寸、位置、可缩放和置顶状态，而不是写死为某个默认尺寸。
- 恢复完整 AppShell 和番茄工作台。
- 页面卸载、路由变化或窗口操作失败时，不遗留紧凑壳状态。

### 失败处理

窗口属性按可回滚顺序切换。任一步失败时恢复已经改变的属性，保持原 UI 模式，并显示错误提示。React 状态只在原生窗口切换成功后更新。

## 实现边界

- 在现有主窗口中切换，不创建第二个 Tauri 窗口，不接入 macOS 私有面板 API。
- 由 AppShell 持有“是否为 Mini 壳”的状态，并通过现有 Outlet context 向 PomodoroPage 暴露进入/退出动作，避免 PomodoroPage 用 DOM 查询隐藏外层组件。
- 窗口快照只保存在当前运行期内；应用重启后使用正常主窗口。
- Tauri capability 仅向 `main` 窗口授予所需的尺寸、位置、可缩放和置顶权限。

## 验收

- 进入 Mini 后不存在 Sidebar、TitleBar 或正常内容容器占位。
- 倒计时和开始/暂停状态与完整番茄页一致。
- 退出后恢复原窗口属性和完整工作台。
- 原生操作失败不进入半切换状态。
- 浏览器预览不会调用 Tauri window API。
- 新增聚焦回归测试，并通过 TypeScript、ESLint、Node 与 Rust 检查；若主分支已有无关失败，须单独记录基线。
