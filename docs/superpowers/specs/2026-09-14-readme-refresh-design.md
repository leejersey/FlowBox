# FlowBox README 全面更新设计

## 目标

在不拆分文档、不改变产品代码的前提下，让根 README 成为 FlowBox 0.5.0 的准确入口：新用户能完成安装和配置，维护者能看懂当前架构，发布记录与本轮实际交付一致。

## 方案

保留现有中文结构与视觉风格，就地校正和精简：

1. 概览与功能区保留，但删除重复、夸张或与实现不符的描述。
2. 快速开始使用锁文件对应的 `npm ci`，补充开发、检查和生产构建命令。
3. 增加首次配置说明，覆盖 AI provider、ASR、Keychain、macOS 权限和可选能力。
4. 根据当前仓库校正技术栈、项目结构、迁移和模块说明，不维护无价值的精确文件数量。
5. Roadmap 仅标记已由源码和测试确认的功能；保留真正未完成项。
6. 重写 v0.5.0 记录，概括本轮数据正确性、后台生命周期、Keychain、autostart、Vision OCR、跨模块关联、懒加载、CI 和质量门禁；历史版本保持原样。

## 边界

仅修改 `README.md`，不改产品行为、不新增依赖、不拆分额外文档。以当前 `main` 源码、配置、测试和 `package.json` scripts 为事实来源。

## 验收

- README 中的命令可由现有 scripts 执行。
- 版本、provider、OCR、安全存储、自启动、关联和 CI 描述与源码一致。
- 不出现已删除的运行时文件或错误的 PaddleOCR/DeepSeek 原生 Vision 描述。
- Markdown 结构清晰，链接和代码块完整。
